# packages/profile — 🧠 兴趣画像

LLM 驱动的用户兴趣画像生成，驱动个性化推荐与「画像透明」红线。

## 定位（L2）

根据用户写过的文字与浏览历史，用 LLM 生成自然语言用户画像（NL profile），捕捉偏好、惯例、行为模式。显式缓解冷启动与可解释性问题，降低对稠密向量 embedding 的依赖。

## 技术参照

- **GenUP**（arXiv:2410.20643）：用 LLM 从大规模行为生成自然语言画像，作为系统提示喂给 LLM 做推荐。开源（CC BY-SA 4.0），是「根据用户行为生成兴趣画像」最直接的 LLM 范式。
- **LLMHG**（arXiv:2401.08217）：LLM + 超图神经网络，可解释推荐——「LLM + 图结构」建模用户-内容-兴趣多维关系。
- **多模态 Embedding 冷启动**（arXiv:2409.17864）：基于内容特征（而非协同过滤历史）解决新用户/新内容冷启动。

tests/

## 画像透明（设计红线）

- 👁️ 用户可查看自己的兴趣画像（NL 标签列表）
- ✏️ 用户可调整画像标签（剔除/加权）
- ❓ 推荐时展示「为什么推荐」——背后的画像依据

## 输出

- 自然语言画像文本（喂给 L1/L2 做推荐系统提示）
- 结构化标签（供 L0 卡片「画像透明」面板展示）
- embedding 向量（供 L2 推荐相似度计算）

## 对接

- 输入：L3 `server` 的用户行为流（发帖/浏览）
- 输出：供 `recommendation` 排序、`ai-service` 策展使用
- 画像缓存在 `services/redis`，定期刷新
